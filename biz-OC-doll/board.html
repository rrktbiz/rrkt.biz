제안함

biz-OC-doll 사이트를 더 편하게 만들기 위한 제안을 받는 곳이에요.

받는 것

  • 사이트를 쓰면서 불편했던 점
  • 있으면 모두가 편할 것 같은 기능
  • 이벤트 진행 방식에 대한 제안

반영 기준

한 번 만들어 두면 그다음부터 저절로 돌아가는 것은 받아요. 작은 수정이든 새 기능이든 상관없어요.

  • 버튼 위치, 문구 한 줄, 불편한 동작 하나 같은 수정
  • 캐릭터 목록의 분류, 필터, 검색, 정렬 같은 기능

만든 뒤에도 공식이 계속 손을 대야 하는 것은 반영하지 않아요.

  • 정기적으로 새 내용을 채워야 하는 코너
  • 올라오는 것마다 공식이 확인하거나 골라야 하는 기능
  • 신청을 받아 하나씩 처리해야 하는 이벤트
  • 홀더 이름 목록, 창작물 모음, 태그 정리 같은 팬덤 정리

이 프로젝트는 운영을 가볍게 유지하는 걸 원칙으로 하고 있어요. 받는 쪽에 해당하는 제안도 모두 반영되지는 않아요.

받지 않는 것

  • 캐릭터의 설정, 이야기, 관계에 대한 제안
  • 새 캐릭터 아이디어나 디자인 요청
  • 캐릭터 해석을 두고 옳고 그름을 가리는 글
  • 특정 홀더나 창작물을 지목하는 글

위에 해당하는 글은 안내 없이 숨겨요.
